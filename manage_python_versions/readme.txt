# Python Environment Manager

Run this script from the same folder as manage_python.sh:

clear && chmod +x manage_python.sh && ./manage_python.sh

This tool helps you:
- check if Homebrew and pyenv are installed
- install Homebrew or pyenv if missing
- install and manage multiple Python versions
- set global or local Python versions
- uninstall Python versions
- detect PATH conflicts between system, Homebrew, and pyenv Python
- repair a broken Python setup

It is mainly used for managing Python versions on macOS/Linux with pyenv.
